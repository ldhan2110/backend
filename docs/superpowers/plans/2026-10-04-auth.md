# JWT Auth + Rotating Refresh Token — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.
>
> **NO-COMMIT MODE:** The user reviews all code before any commit. Every task's

> or commit anything.

**Goal:** Reusable JWT authentication — register, login, rotating refresh (httpOnly cookie), logout, `me` — with a Redis-or-in-memory refresh-token store, secure-by-default global guard.

**Architecture:** Access token = stateless JWT (signature-only verify, 0 store hits). Refresh token = JWT with `jti`, stored (hash) in Redis or in-memory, rotated every refresh, revocable. Plain `@nestjs/jwt` + custom guard (no Passport). Access in response body (Bearer), refresh in httpOnly cookie scoped to `/auth/refresh`.

**Tech Stack:** NestJS, `@nestjs/jwt`, `bcrypt`, `ioredis`, `cookie-parser`, SqlMapper (raw-SQL, `#{}` params), `@nestjs-cls/transactional`, class-validator, Jest.

## Global Constraints

- **Data access = SqlMapper only.** `named('<file>.<query>')`, `#{}` params only, no `${}`, no TypeORM repo/query-builder at runtime.
- **Transactions = `@Transactional()` on the service write method.** Never controller/repository. No manual `QueryRunner`/`DataSource`.
- **Path aliases** `@infra @config @common @modules` — never relative `../../..`.
- **File names:** `<n>.module.ts`, `.controller.ts`, `.service.ts`, `.repository.ts`, `.sql`, `.request.dto.ts`, `.response.dto.ts`.
- **Request DTOs** have no audit fields; validated with class-validator. **Response DTOs** extend `BaseDto` (`@common/dtos/base.dto`).
- Business-rule violations throw a `DomainException` subclass (`@common/exceptions`).
- `synchronize=false` — schema only via migration.
- **`users` PK is `user_id` (varchar)** — deliberate override of `migration.md`'s "PK: id". Do not revert.
- Comment only non-obvious *why*. Mark deliberate shortcuts with `// ponytail:`.

```ts
import { Injectable } from '@nestjs/common';
import { RefreshTokenStore } from './refresh-token.store';

// ponytail: in-memory store, single-instance/dev only — set REDIS_URL for prod
@Injectable()
export class MemoryRefreshTokenStore implements RefreshTokenStore {
  private readonly map = new Map<string, { hash: string; expiresAt: number }>();
  private key(u: string, j: string) { return `refresh:${u}:${j}`; }

  async save(userId: string, jti: string, tokenHash: string, ttlSec: number) {
    this.map.set(this.key(userId, jti), { hash: tokenHash, expiresAt: Date.now() + ttlSec * 1000 });
  }
  async get(userId: string, jti: string) {
    const e = this.map.get(this.key(userId, jti));
    if (!e) return null;
    if (e.expiresAt <= Date.now()) { this.map.delete(this.key(userId, jti)); return null; }
    return e.hash;
  }
  async del(userId: string, jti: string) { this.map.delete(this.key(userId, jti)); }
  async delAll(userId: string) {
    const prefix = `refresh:${userId}:`;
    for (const k of this.map.keys()) if (k.startsWith(prefix)) this.map.delete(k);
  }
}
```
